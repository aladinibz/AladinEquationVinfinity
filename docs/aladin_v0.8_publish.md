# ALADIN v0.8 — Universal Plasma Stability Criterion

**ALADIN** (Axisymmetric Loaded Advanced Dynamics In Nonlinear plasmas) is a scaling-derived stability criterion for current-driven plasmas.

**Law**: Instabilities are suppressed when  
**Π = μ₀ J₀² R² / (ρ₀ c²) ≳ O(10)**  
with calibrated threshold **Π_crit ≈ 8** in high-resolution limit.

**Corollary for relativistic jets**: Π_rel = Π / γ² ≳ 8 / γ²
