# Kink Mode Damping Mechanisms Comparison

**ALADIN ∞ ℂ(t) — Plasma Proof**

Compares resonant absorption (fast exponential) vs phase mixing (slow power-law) damping for kink modes.

### Resonant Absorption
γ / ω₀ ≈ - (π/2) × (ρ_i - ρ_e)/(ρ_i + ρ_e) × (δ/L)  
Typical: τ ≈ 10–100 s (exponential decay)

### Phase Mixing
A(t) ∝ t^{-1/3}, γ(t) ≈ - (1/3t) × (Δω_A / ω₀)^{2/3}  
Typical: slow fade over minutes–hours

### Interpretation
Hybrid behavior: fast initial drop (resonant) + long tail (phase mixing). Explains SDO "decayless" observations.
